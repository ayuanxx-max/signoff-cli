# 品牌与商标政策（主体暂用占位名）

本文件是本项目「谁拥有什么、什么时候能写 ™、怎么拿到 ®」的唯一口径。
`docs/legal.md` 讲法律边界，本文件讲**具体做法与排他方案**。

## 1. 主体：现在写什么

| 位置 | 现在写 | 定名后改成 |
| --- | --- | --- |
| `LICENSE` | `Copyright (c) 2026 SignOff contributors` | 真名或公司全称（个人写姓名，公司写工商全称） |
| `NOTICE` / `README` 代码行 | `© 2026 SignOff contributors` | 同上 |
| 标志、名称、插图 | `© 2026 SignOff` | 同上 |
| 标志边款（图形内） | `© 2026 SignOff` | 同上，需重导 SVG/PNG |

**`SignOff` 是占位主体**，不是法律主体。定名后要改的只有四处：`LICENSE`、`NOTICE`、`README.md`/`README.en.md` 各一行、标志边款（重导图）。
`tools/` 里没有自动替换脚本，因为改主体必须人工确认一次。

## 2. ™ 怎么用（现在就能用）

- **™ 不需要注册**，是"我主张这是商标"的声明，任何人在任何类别都能写。
- 写法：紧跟名称右上角，`SignOff™`、`落印™`；中文里也可写「落印™」。不加空格。
- **只在首次出现的位置标一次**，不要每段都标——标多了像广告，不增加任何权利。
- **未注册不得写 ®**。中国《商标法》把未注册而标 ® 定为「冒充注册商标」，可被责令改正并罚款。
- 我们现在的用法：`README` 标题行、`NOTICE` 名称节、标志 `alt` 文本。

## 3. 排他：要注册什么

### 3.1 申请标的（三件一组）

| 标的 | 说明 | 显著性 |
| --- | --- | --- |
| 文字 `SignOff` | 英文名 | 弱：常见英文短语（"签退"），易被认定描述性 |
| 文字 `落印` | 中文名 | 中：臆造组合，显著性较好，建议作为主商标 |
| 图形（S 印章标志） | 现用标志 | 强：图形独创，最稳的一件 |

策略：**先申「落印」文字 + 图形**（显著性够、驳回风险低），`SignOff` 文字作为组合商标的一部分递（`落印 SignOff` + 图形），避免单独因描述性被驳。

### 3.2 类别（中国 CNIPA，一标一类）

| 类别 | 覆盖什么 | 是否必须 |
| --- | --- | --- |
| **第 9 类** | 可下载软件、计算机程序 | 必须 |
| **第 42 类** | 软件设计开发、SaaS、技术咨询、平台服务 | 必须 |
| 第 35 类 | 广告、商业管理、平台代运营（若做商业化/市场） | 建议 |
| 第 41 类 | 培训、出版、在线内容（若做教程/课程） | 可选 |

### 3.3 费用与时间（中国，以官方公告为准）

| 项 | 数值 |
| --- | --- |
| 官费 | 网上申请约 **270 元/类**（限 10 个商品项，超出每项加收） |
| 代理费 | 600–1500 元/类（自行申报可省） |
| 受理通知书 | 约 1 个月 |
| 实质审查 | 约 4–6 个月 |
| 初审公告 + 异议期 | 3 个月 |
| 顺利拿证 | **约 7–10 个月** |
| 有效期 | 10 年，期满前 12 个月续展 |

两件核心类别（9 + 42）× 两件标的（`落印`、图形）＝ 4 件，官费约 1080 元；加 `落印 SignOff` 组合再 2 件。

### 3.4 国际（有需要再走）

| 途径 | 覆盖 | 成本量级 |
| --- | --- | --- |
| 马德里体系 | 一份申请指定多国，需国内基础申请/注册 | 基础费 + 每国指定费，约 1–3 万元 |
| 美国 USPTO | 单国 | 官费约 250–350 美元/类 + 代理 |
| 欧盟 EUIPO | 27 国 | 首类约 850 欧元 |

先把中国做扎实；开源项目的主要风险在国内平台抢注与 npm 名称，不是海外。

## 4. 申请前必做：检索

1. **CNIPA 商标查询**（`sbj.cnipa.gov.cn`）按「落印」「SignOff」做文字近似检索，覆盖第 9、42 类。
2. 图形检索：用标志的**黑白线稿**做图形要素检索（去掉颜色后比对）。
3. 平台检索：GitHub、npm、V2EX、即刻、小红书搜同名项目，判断是否已有在先使用。
4. 域名与账号：`signoff` 相关域名、GitHub org、npm scope、微信公众号名，能注册的先占住。

## 5. 使用证据（现在就开始存）

异议、无效、维权都要证据。建议每季度归档一次到 `docs/evidence/`（不进 npm 包）：

- 最早提交记录：`git log --reverse --format='%ad %H %s' | head -1`
- npm 首次发布时间与版本（`npm view signoff-cli time`）
- GitHub Release 页面截图/URL、下载量
- 带标志的对外物料：README 渲染图、文章、视频封面

## 6. 拿到注册后要做什么

1. 把 `™` 换成 `®`——**只在注册的类别和地区**用，别在未注册类别上标 ®。
2. `README`、`NOTICE` 加注册号与注册类别。
3. 建立监测：每半年检索一次近似商标；发现抢注在初审公告 3 个月内提异议。
